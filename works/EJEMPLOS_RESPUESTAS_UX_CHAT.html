Ejemplos de respuestas UX

Banca Conversacional — cards contextuales, continuidad de campo, opciones formateadas, Markdown seguro, contactos accionables y procesos organizados.

Contrato Swagger 1. Cards por campo 2. Opciones listadas 3. Fecha sin conflicto 4. Contactos accionables 5. Proceso largo Validación QA
Validación en QA (:8447, 16/09/2026): todas las respuestas se capturaron mediante POST /turn con customer_id=726588. Como el Core de ese usuario no contiene certificados ni tarjetas, para esta prueba contractual se cargó explícitamente qa_726588_contract_demo.json, una extensión sintética y aislada del portafolio real. No modifica los datos del Core.

Contrato Swagger / OpenAPI 3.1

Fuente completa: schemas/turn_api.openapi.yaml. Endpoint documentado: POST /turn. Swagger interactivo del servicio: http://20.127.25.24:8447/docs.

Campos del request

CampoTipoUso
questionstring|nullPregunta libre o selection.message al pulsar una card.
selected_option_refstring|nullReferencia opaca de la opción seleccionada; el front no debe construirla.
conversation_idstringIdentificador estable que conserva pending, foco y continuidad.
customer_idstringCliente autenticado cuyo snapshot puede consultarse.
client_idstring|nullAlias de compatibilidad usado por algunos canales APK.
top_kinteger|nullLímite opcional de resultados para consultas RAG.
force_core_querybooleanSolicita generar core_channel cuando aplique.
context_infobooleantrue carga/refresca contexto; false procesa lenguaje natural.
context_opload|refresh|nullOperación de contexto cuando context_info=true.
contextobject|nullEnvelope de datos Core enviado por el orquestador.

Campos principales del response

CampoTipoUso en frontend
app_channelobjectContrato canónico que debe renderizar el frontend.
app_channel.statusenumVALID_CONTRACT, requires_selection, aclaración, no operacional o error.
client_responsestringFallback plain/Markdown cuando no se consume rich content.
content_formatplain|markdownIndica cómo interpretar el fallback textual.
rich_contentobject|nullBloques versionados: paragraph, list, section, card_group y actions.
optionsProductOption[]Cards con título, subtítulo, campo contextual, moneda y selección.
options[].contextobjectfield, label, formatted_value y currency.
options[].selectionobjectselected_option_ref y pregunta contextual message.
clarificationsarrayRequisitos faltantes y pregunta de aclaración.
suggested_questionsarrayAcciones conversacionales opcionales.
intent_idstring|nullIntent operativo resuelto.
account_refstring|nullReferencia interna del producto ya resuelto.
core_channelobject|nullSolicitud estructurada hacia Core cuando corresponde.
auditobjectMétricas técnicas; no deben mostrarse al cliente.
reply/message/contentstringAliases de compatibilidad de client_response.
