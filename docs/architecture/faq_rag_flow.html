FAQ vs RAG — cómo está implementado hoy

Genesis Cognitiva (8447). Respuesta corta: sí hay base vectorial (Azure AI Search), pero el path feliz de FAQ no la consulta. Primero gana el match lexical del JSON/overlay; Azure Search solo entra cuando el fastpath falla y el intent es conocimiento de negocio.

¿Base vectorial?

Sí — Azure AI Search

Campo content_vector + embeddings Azure OpenAI.

¿FAQ usa vectores?

No

Match léxico sobre kb_faq_vf01.json + overlay.

¿RAG en /turn?

Solo path knowledge

Si fastpath miss + BUSINESS_KNOWLEDGE_QUERY + Search ready.

¿Vector DB local?

No (FAISS/Chroma)

local_rag.py es cliente Azure (nombre histórico).

Flujo de un turno (orden real)

FAQ lexical KB intent (MD/JSON overlap) RAG vectorial Azure
1

Usuario → POST /turn → inspect

Sesión + snapshot. Aún no hay FAQ ni Search.

↓
2

Fast-path determinista FAQ sin vectores

run_field_fastpath → apply_faq_guardrail / match_faq. Carga data/kb_faq_vf01.json + kb_faq_overlay_fase1.json. Scoring por tokens/expresiones (umbral ~0.78; institucional ~0.65). Hit → responde y termina (misión, catálogo, “qué es…”, etc.).

↓ miss
3

Dentro del FAQ: kb_intent_resolver overlap sin vectores

Si el FAQ exacto no alcanza, intenta overlap sobre el mismo corpus JSON + markdown en Knowledge_Base/excel_vf01/*.md. No embebe ni consulta Azure Search.

↓ aún miss → LLM
4

Clasificadores + turn-decision (LLM)

Dominio business → intent BUSINESS_KNOWLEDGE_QUERY.

↓
5

RAG Azure vectorial sí consulta Search

LocalRagStore.query en rag/local_rag.py: embedding de la pregunta → vectorQueries sobre el índice Azure AI Search → top chunks → generate_rag_answer (LLM grounded).

↓ NO_HITS / Search no ready
6

Cascada de fallback

FAQ otra vez → KB intent → fallback institucional → (opcional) humano.

Dos motores, lado a lado

FAQ

Respuestas tipadas, rápidas, sin LLM

Fuente: Excel VF01 → JSON + overlay Fase 1.
Match: expresiones / sinónimos / topic.
Archivos: faq_guardrail.py, kb_faq_*.json.

RAG

Huecos / conocimiento largo

Fuente: índice Azure (chunks de KB).
Match: embedding + similitud vectorial.
Archivos: local_rag.py, index_kb_azure.py.

¿Cuándo se consulta la base vectorial?

Pregunta ejemplo Camino típico ¿Azure Search?
“Misión”, “hablame del banco” FAQ fastpath No
“qué es un certificado de depósito” FAQ overlay (tras el fix) No
“cuál es la tasa de mi DAP 5511” Snapshot personal (templates) No
Knowledge sin FAQ fuerte, Search ready LLM → BUSINESS_KNOWLEDGE → RAG Sí
RAG sin hits / índice vacío FAQ → kb_intent → institucional Intentó Search; fallback lexical
